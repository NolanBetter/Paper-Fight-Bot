Install

Paper, Bukkit, Purpur or Spigot on 1.16 or newer. Four minutes to your first fight.

Do you need LibsDisguises? Only on plugin versions below 4.1.0, where it is what makes the bots look like players. From 4.1.0 onward the plugin stands alone and you can skip it entirely. If you are installing fresh today, you only need one jar.

Download the jar

Grab the newest full release from Modrinth. Betas are there too, but start on a stable build unless you are chasing a specific fix.

Open Modrinth

Drop it in and restart

Put the jar in your server's plugins folder and do a full restart, not a reload. The plugin writes its config.yml and botnames.yml on first boot.

On an older build, install the free LibsDisguises alongside it before restarting.

Spawn a bot

Join the server and run this. You get a bot with a random player‑style name at your feet.

/fightbot spawn --random 1

# or name it yourself
/fightbot spawn Kade

Gear it up

Switch to creative and right‑click the bot to open its equipment screen. Fill the slots with whatever you want it fighting you with — armour, sword, totem, axe, food, pearls, webs, water bucket. Or skip this and fight it bare‑handed.

Full slot list is in the wiki.

Point it at yourself

Now it hunts you.

/fightbot fight Kade YourUsername

# had enough
/fightbot stop --all
Permission: everything sits under fightbot.use, which defaults to OP. Grant it in your permissions plugin to let other people spawn bots.
